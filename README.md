# Угадай число

Игра загадывает число, а вы угадываете: на каждую догадку она отвечает «больше», «меньше» или «угадал».

- `src/` — код игры на TypeScript, его не меняют.
- `docs/` — сюда игра собирается; тут же `game.json` с текстами — тема, приветствие, режимы и сообщения.
- `npm install` — один раз, ставит сборщик; `npm start` — собрать и сыграть в терминале; `npm test` — проверить игру.
